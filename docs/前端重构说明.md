## 关键改动及理由

1. **组件拆分**：`App.vue` 609 行 → 140 行；`ChatPanel.vue` 643 行 → 170 行。拆分后 `AssistantMessage` 独立成组件，流式输出时 markdown 重渲染只作用于当前消息（此前每个 token 触发整列表 `renderMarkdown`）。
2. **逻辑下沉 composables**：流式对话（useAgentChat）、健康轮询（useHealth）、侧栏状态（useSidebar）与视图解耦，行为逐行保留（含注释中的设计决策）。
3. **消除重复**：`uid` ×2、来源条目 UI ×2（SourceList/KnowledgePanel）、`pickList`/来源归一化 ×3 全部收敛到 utils/common 与 SourceCard。
4. **样式体系**：组件内硬编码色（#f8fafc/#f1f5f9/#fbfdfe/#991b1b/#fffbeb 等）收敛为 token；新增 focus-visible 焦点样式与 `prefers-reduced-motion` 支持。
5. **响应式**：≤860px 侧栏变浮层抽屉 + 遮罩 + 聊天头部汉堡按钮；消息区/输入区窄屏适配；两个管理抽屉窄屏全宽；`100dvh` 适配移动浏览器；登录弹窗 `min(380px, 92vw)`。
6. **性能**：管理面板 `defineAsyncComponent` + 首开懒加载（普通用户不加载 5.5KB/8.8KB chunk）；vite manualChunks 拆分 vendor(302KB)/element-plus(814KB)/markdown(70KB)，利于长缓存；`v-model` 写法统一为 `defineModel`（UserPanel 原为 props/emit）。

## 行为保持不变的部分

- 启动顺序：initSessions → 装 401 处理器 → bootstrapAuth → 健康轮询（30s）
- 发送/停止/切换会话中断生成；done 事件兜底 clarify；会话 localStorage 持久化时机
- 所有接口路径、鉴权显隐逻辑、校验规则、文案
